# ITO 季度考核与任务 SLA 说明

> 版本：v3.1
>
> 口径：Q1–Q4 完整季度记录；当前季度 2026 Q4；全部分数为整数
>
> 适用范围：驾驶舱 09、后台「运营统计 / 团队统计 → 考核」、季度运维复盘

## 1. 文档目的

09 面板与后台考核页不再以单月成绩作为正式考核结果，而是回答：

1. 当前季度考核总分是多少，是否达到 95 分合格线？
2. 当前季度已经记录了多少扣分、加分和安质环状态？
3. Q1–Q3 历史季度结果如何，和当前季度相比有什么变化？

任务 SLA 92.0 仍保留，但只作为「任务时效参考」，不计入考核总分。

## 2. 考核结构

```text
考核总分 = SLA 考核得分（满分 80） + 安质环得分（满分 20）
合格线 = 95 分
```

季度 SLA 按季度累计扣分 / 加分重算，所有分数均为整数。

## 3. 计算规则

### 3.1 SLA 考核

```text
SLA 考核 = min(80, 80 + 季度加分合计 - 季度扣分合计)
```

- 加分项按季度合并后，每项最多计 2 次；
- 月度不单独计分，月度只作为季度事件的归集来源；
- 扣分项按事件次数计；
- SLA 考核最低 0 分，最高 80 分；
- 季度内所有已发生月份的扣分 / 加分都计入季度合计。

### 3.2 安质环

```text
红灯 / 一票否决 > 0：安质环 = 0
否则：安质环 = max(0, 20 - 安质环扣分合计)
```

- 安质环按季度考核文档 26 条逐项扣分；
- 出现红灯 / 一票否决项时，当期安质环归零；
- 黄灯事件按对应标准扣分，不再统一按“不扣分”处理；
- 单项扣分累计，最高扣 20 分，扣完为止。

### 3.3 任务 SLA 参考

```text
任务 SLA = 按期闭环率 × 60%
         + 超期控制率 × 25%
         + 时效达成率 × 15%
```

当前任务 SLA 为 **92.0 分 / A 级**，仅用于任务时效分析，不进入考核总分。

## 11. 常见问题

### 为什么 09 不显示 92.0 了？

92.0 是任务时效参考分，不是季度考核总分。09 显示当前季度考核总分 96，任务 SLA 放到后台考核页作为参考。

### 为什么季度分没有小数？

季度 SLA 直接按季度累计扣分 / 加分重算，安质环只取 0 或 20，因此所有分数都是整数。

### 为什么 Q1/Q2/Q3 都是 95？

Q1–Q3 每季 SLA 扣分 15、加分 11，SLA 为 80 + 11 - 15 = 76；安质环扣 1 分，得分 19；总分 95。

### 为什么 Q4 是 96？

Q4 当前累计 SLA 扣分 13、加分 11，SLA 为 80 + 11 - 13 = 78；安质环扣 2 分，得分 18；总分 96。

### 触发红灯后分数怎么算？

触发任一红灯 / 一票否决项，当期安质环归零；当前 Q4 若出现红灯，总分将变为 SLA 78 + 安质环 0 = 78，低于合格线。
