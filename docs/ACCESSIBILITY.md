# 无障碍审计报告 · ITO 智能运维平台

> 版本：`20261112z22`  
> 审计日期：2026-11-11  
> 范围：本地演示版（`index.html` + `admin.html`），不包含真实上线、后端、SSO、服务端权限与外部通知渠道。
> 演示硬件：65 寸大屏，观看距离约 2 米；鼠标 + 键盘操作。

## 1. 结论

- 驾驶舱、登录页、后台 18 个路由，共 20 个页面/入口：**axe 全规则（含 best practice）0 违规**。
- 13 个关键弹窗：**WCAG 2.1 A/AA 0 违规**；6 个重点弹窗全规则抽检 **0 违规**。
- 键盘走查、模态框焦点陷阱、焦点返回、自定义下拉键盘操作、行详情键盘入口均通过。
- 大屏在 1920 × 1080、1600 × 1000、3840 × 2160 下均无页面横向溢出；关键控件在 1920 下为 26–32px，2 米距离可用。
- 未改变驾驶舱默认字号和版式；无障碍改动以对比度、焦点、语义、键盘操作和减少动效为主。

## 3. 审计方法

1. **axe-core 4.10.2**：先按 WCAG 2.1 A/AA 扫描，再做全规则（含 best practice）扫描。
2. **键盘走查**：Tab / Shift+Tab、Enter / Space、Esc、方向键、Home / End、焦点可见、无键盘陷阱。
3. **焦点管理**：弹窗初始焦点、焦点陷阱、关闭后返回触发元素、路由切换后焦点移到页面标题。
4. **语义检查**：landmark、标题层级、按钮 / 链接角色、`aria-current`、`aria-expanded`、`aria-selected`、表格 `scope`、表单 label、错误提示 `role="alert"`。
5. **视觉检查**：正文 4.5:1、大字 / UI 3:1、颜色不是唯一信息、200% 缩放、文字间距。
6. **动效检查**：`prefers-reduced-motion`、沙盘自动轮播、快讯滚动、ECharts 动画、暂停按钮。
7. **大屏检查**：65 寸 / 2 米、1920 与 4K、鼠标命中区域、焦点环可见性、投影对比度抽检。

## 4. 初始问题与修复

### 4.1 对比度

初始 axe 在后台多个页面报告 serious 对比度问题，集中在：

- 筛选占位文字 `#AEAEB2` 对白底 **2.21:1**
- 绿色状态徽章 `#178A49` 对 `#E8F8EE` **4.00:1**
- 红色徽章 `#E5484D` 对 `#FDECEC` **3.42:1**
- 黄色徽章 `#C77A00` 对 `#FFF4DF` **3.09:1**
- 蓝色徽章 `#0A72E8` 对 `#E9F1FE` **4.03:1**
- 紫色徽章 `#7A5AF8` 对 `#F0EDFE` **3.92:1**
- 角色 / 授权 / 组代码 / 标签类型等小字号彩色文字

修复方式：

- 新增 `--green-ink / --red-ink / --yellow-ink / --blue-ink / --purple-ink` 文本色，专用于浅色底上的小字。
- `--muted` 调整为 `#6B6B70`，`--dim` 调整为 `#6E6E73`，`--ink-3` 调整为 `#5F5F65`。
- 品牌文字色 `--brand-deep` 调整为 `#A83E12`；主按钮与激活页签使用 `--brand-strong #C2501C` / `--brand-stronger #B44617`。
- 后台橙色外壳整体加深一档，保证白色侧边栏文字与 `--shell-muted` 达到 4.5:1。
- 驾驶舱 `--dim` 从 `#4F7392` 提亮到 `#6F95B6`，在 `#061A30` 面板上约 **5.55:1**。

### 4.2 嵌套交互

任务表整行 `tr[role="button"][tabindex="0"]` 内包含展开、编辑、查看成果物等按钮，axe 报告 `nested-interactive` 10 行。

修复：

- 整行不再作为键盘按钮；任务名改为 `<button class="task-name-text" data-act="detail">`。
- 鼠标仍可点击整行；键盘通过任务名按钮进入详情。
- 行内其他操作按钮保持独立焦点。

### 4.3 表单与自定义下拉

- `formRow` 自动生成 `label[for]`、`aria-required`、`aria-describedby`，并保留原控件 id。
- 自定义字段、子任务行等没有显式 label 的控件，按列头 / placeholder 补 `aria-label`。
- 自定义下拉补 `aria-expanded`、`aria-controls`、`aria-selected`，支持方向键、Home / End、Esc；必填状态写入触发器名称。
- 字段错误提示补 `role="alert"`、`aria-invalid`、`aria-describedby`。

### 4.4 弹窗 / 抽屉

- 打开时给 `#appView` 加 `inert`，关闭时移除。
- 弹窗与抽屉均支持 Tab 焦点陷阱、Esc 关闭、关闭后焦点返回。
- 弹窗内容滚动区在无内部可聚焦元素时补 `tabindex="0"` 与 `role="region"`。

### 4.5 导航、路由与表格

- 增加“跳到主内容”链接，仅在键盘聚焦时出现。
- 路由切换后焦点移到页面 `h1`，并通过 `aria-live` 播报“XX 页面已加载”。
- 侧边栏 `aria-current="page"`，移动菜单 `aria-expanded`，侧边栏补 `aria-label`。
- 表头补 `scope="col"`，表格补 `aria-label`；可滚动表格区域可键盘聚焦。
- 可点击行补键盘入口：整行或行内第一个非交互单元格支持 Enter / Space 打开详情。
- 标题层级修正：表格 / 图表标题提升为 `h2`，必要时插入视觉隐藏的 `h2 / h3`，避免 h1 → h3 / h4 跳级。

### 4.6 大屏专项

- 焦点环从 1px 改为 3px 青蓝；面板内使用内缩焦点环，避免被斜切角或 `overflow` 裁切。
- 顶栏控制 32×32、沙盘按钮 / 状态 28×28、趋势切换最小高度 26px；顶部状态文本通过伪元素扩展命中区。
- 面板行、流程节点、消息、维保排期补 hover 高亮与鼠标指针。
- `Space` 在按钮上只激活按钮，不再被沙盘全局快捷键抢占；`←` / `→` 切换沙盘状态。
- `prefers-reduced-motion` 下沙盘默认暂停，快讯与脉冲动画停止。
- 1920 / 1600 / 3840 三个视口验证，4K 下按 2 倍缩放，无溢出。
- 未改默认字号；65 寸 2 米距离下，主数字与中文标签可读，英文微标签作为辅助信息保留。

## 6. 残留风险与边界

1. **未做真人读屏用户测试**：使用 axe + Chromium 无障碍树 + 键盘走查；未邀请 NVDA / Narrator 用户做完整任务测试。
2. **ECharts 文本替代**：图表容器使用 `role="img"` 与 ECharts 自动摘要 / `aria-label`，没有提供完整数据表替代。
3. **固定 1920 驾驶舱**：大屏不使用浏览器 200% 缩放作为无障碍机制；已按 1600 / 1920 / 3840 和 65 寸 2 米验收。若未来要求大屏浏览器缩放，需要额外的大屏模式或重排视图。
4. **表格行详情模式**：部分行使用“行内单元格作为按钮”的键盘入口，读屏会按单元格 / 按钮混合播报；axe 通过，但不是最理想的表格语义。
5. **通知卡片**：右上角通知 6 秒自动消失，演示中可能短暂覆盖页面头部操作；键盘可 Tab 到关闭按钮。
6. **浏览器覆盖**：只验证 Edge / Chromium；Safari、Firefox 未验证。
7. **真实上线**：未包含后端、SSO、服务端 RBAC、文件服务、邮件 / 短信 / Webhook 等生产能力。

## 7. 复现方式

```bash
python -m http.server 4173
```

- 驾驶舱：`http://127.0.0.1:4173/?still=1`
- 后台：`http://127.0.0.1:4173/admin.html?role=manager&still=1#/tasks`
- 登录页：`http://127.0.0.1:4173/admin.html?login=1`

建议检查顺序：

1. 登录页 Tab 到“跳到主内容”以外的角色按钮。
2. 后台任务页 Tab 到任务名，Enter 打开详情，Esc 关闭，确认焦点返回。
3. 任务页筛选下拉，Enter / 方向键 / Esc。
4. 新建任务弹窗，Tab 循环不跑出弹窗。
5. 巡检执行弹窗，字段错误提示可被读屏识别。
6. 驾驶舱 Tab 到顶栏暂停按钮，Space 暂停 / 恢复；Tab 到面板行，Enter 下钻。
7. 系统开启“减少动效”后刷新驾驶舱，确认沙盘默认暂停。
