## 1. 一句话定位

这是一个“运维指挥中心 + 运维管理后台”的双端系统：

- **大屏**回答“现在系统健不健康、哪里有问题、谁在处理”；
- **后台**回答“任务怎么派、怎么审批、巡检维保值班怎么管、绩效怎么算”。

它不是通用 CRUD 后台，也不是营销落地页；两端共享同一份演示数据。

## 3. 核心数据流

```text
大屏发现问题
  → 后台派发任务
  → 执行人执行、提交成果
  → 负责人审批
  → 领导下发任务再进入汇总报审 / 领导审批
  → 闭环
  → 工时进入负载
  → 结果进入月报与季度考核
```

另外三条支流：

```text
巡检异常 → 自动生成整改任务 → 派发 → 执行 → 审批 → 闭环
维保计划 → 登记记录 → 下次维保日期顺延
值班 → 出勤 8h/天 → 工时负载
```

所有环节共用同一份数据，关键操作写入操作日志。

## 6. 任务全生命周期

状态：

```text
草稿 → 待分发 → 执行中 → 审批中 → 已完成
```

分支：

- 审批驳回 → 退回执行中；
- 超过 72 小时未审批 → 已挂起；
- 重新提交 → 审批中；
- 取消 → 已取消；
- 草稿、待分发、执行中、审批中、已挂起可取消。

关键规则：

- **不拆分**：一条主任务对应一条执行任务；
- **拆分**：父任务下多条子任务，分别派发、执行、审批；
- 父任务截止取最晚、等级取最高、类型归为“综合”；
- 草稿不计入在办、新增、超期；
- 发起人只选领导 / 主管 / 组长；
- 负责人只选主管 / 组长；
- 执行人排除领导；
- 任务编辑、改派、取消受状态和角色限制。

## 7. 领导下发任务的特殊流程

```text
领导下发
  → 执行人提交成果
  → 负责人审批
  → 待汇总
  → 负责人汇总报审
  → 领导审批
  → 已完成 / 审批驳回
```

- 负责人审批通过后，普通任务直接闭环；领导下发任务进入“待汇总”；
- 负责人汇总成果、填写汇总说明并提交领导审批；
- 领导审批 72 小时未处理 → 领导审批挂起；
- 领导驳回可以选择退回执行或直接关闭。

---

## 8. 巡检 → 整改

1. 巡检计划按周期生成执行任务；
2. 执行人填写实际工时、巡检结果、检查项、异常项、说明；
3. 正常 → 记录归档，计划顺延到下一周期；
4. 异常 → 自动生成一条“异常整改”主任务，进入派发与执行；
5. 整改任务完成后，巡检异常才真正闭环。

---

## 9. 维保

1. 维保计划包含厂商、执行人、标准工时、下次维保日期；
2. 登记维保记录：结果、实际工时、更换部件、遗留问题；
3. 提交后记录归档，下次维保日期按周期顺延；
4. 维保计划数、启用数、下次日期同步到大屏 10 面板。

---

## 10. 值班与工时

- 值班以周为单位排班；
- 通信助理固定，应急 / 线路 / 网络 / 桌面 4 个角色轮换；
- 只有通信助理本人、领导、全局管理员可编辑 / 导入 / 保存值班表；
- 值班管理页不展示出勤列、出勤 KPI、出勤记录；
- 出勤按天 8 小时计入工时负载，待命不计；
- 出勤明细在工时负载页点击人员行查看。

工时负载：

- 周容量 40h、月容量 160h；
- 负荷 = 已记录实际工时 + 剩余计划工时 + 值班工时；
- 超过 80% 标黄，承接后超过 100% 标红并弹确认；
- 缺少授权也会提示，但允许主管确认继续；
- 点击人员行可查看任务工时流水 + 出勤记录。

## 11. 季度考核与月报

季度考核：

- 只按季度计分；
- Q1 / Q2 / Q3 均为 95 分，Q4 为 96 分；
- Q4：SLA 78/80 + 安质环 18/20，扣 13、加 11；
- 月度只作为扣分 / 加分事件来源，不单独形成月度得分；
- 安质环按 26 条标准逐项扣分，红灯 / 一票否决归零；
- 季度明细可查看 51 + 7 条 SLA 标准与 26 条安质环标准；
- 任务 SLA 92.0 分只是任务时效参考，不计入考核总分。

月报：

- 范围：我的 / 专业组 / 组员 / 员工 / 我发起；
- 员工月报支持专业组筛选与人员搜索；
- 月报包含任务、勋章、工时、AI 解读；
- AI 解读是本地演示引擎，不是真实大模型决策；
- 下载前先预览，导出 HTML 包含 AI 文本与任务表。

## 13. 组织、授权、标签、权限

- 4 个专业组、40 名成员；
- 成员档案含能力标签、属性勋章、作业授权、操作记录；
- 作业授权：12 类只读矩阵，60 天有效 / 临期 / 过期，不提供发放、续期、撤销；
- 属性勋章：50 个人员标签、70 个任务标签；
- 角色：
  - 领导：团队任务、运营统计、考核、全部专业组；
  - 主管：我的任务、团队统计、考核、本组；
  - 员工：我的任务、个人统计、值班、我的授权；
  - 管理员：组织、标签、字典、预警、角色、日志；
  - 全局：全模块调试身份，配置中心隐藏；
- 字典配置默认仅管理员可见，可在角色权限中开放给其他角色；
- 所有关键操作写入操作日志。

## 17. 推荐演示主线

1. 开场：运维从“人盯人”转向“任务在线、过程留痕、数据说话”；
2. 大屏：健康、流量、审批积压、超期、巡检异常；
3. 下钻：09 考核看 SLA 与安质环，说明考核不是月底补表；
4. 后台：把大屏发现的问题走完“派发 → 执行 → 审批 → 闭环”；
5. 巡检 / 维保 / 值班：说明日常运维如何被任务化；
6. 工时与权限：资源负荷、授权、审计；
7. 收尾：任务、异常、工时、考核都能追溯，形成闭环。

## 18. 表达边界

- 演示环境 + 模拟数据，不是真实生产系统；
- 数据存在浏览器 `localStorage`，不是后端数据库；
- 大屏是态势视图，后台才是操作端；
- 授权矩阵只读；
- 月报整页展开；
- 主任务详情不汇总子任务执行字段，执行结果在子任务详情看；
- AI 月报是演示文本生成；
- 真实全屏、跨午夜刷新属于环境限制，不主动展开；
- 固定 `?asof=2026-11-30`，页面显示真实日期，数据截止 11 月 30 日。
