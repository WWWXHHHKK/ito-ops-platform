- 浏览器：Chrome / Edge，100% 缩放。
- 后台窗口：2549 × 1403；补测 2560 × 1600、125% / 150% 缩放。
- 大屏窗口：1920 × 1080。
- **常规测试使用 4173 端口，绑定 `127.0.0.1`；离线包可另用 4300，避免占用开发服务。**
  - 大屏：`http://127.0.0.1:4173/`

- 固定数据截止日，页面显示真实日期（只固定数据日期，操作时间跟随系统时钟）：

  - `index.html?asof=2026-11-30&still=1&v=20261120z89`
- 开始前重置：
  - `admin.html?reset=1&asof=2026-11-30&v=20261120z89`
- 身份：
